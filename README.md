# BeepAC
Simple script to play a beep every upshift or downshift for Assetto Corsa and tell the delta colors of lap sectors. This is using the default mapping of Y for downshift and A for upshift. Open the code inside VS code and run it on the terminal. Stop the code from running by pressing Ctrl + C on the terminal.
